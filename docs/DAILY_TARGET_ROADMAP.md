## 📅 4-Week Milestone (အပတ်စဉ် အဆင့်ဆင့် လျှောက်လှမ်းမည့် အစီအစဉ်)

### 🔹 Week 1: SQL Mastery for Payroll & HR Data
- [ ] **Day 1:** Environment Setup & Relational DB အခြေခံ (`SELECT`, `WHERE`, `ORDER BY`, `LIMIT`)
- [ ] **Day 2:** Data Aggregation & Business Summary (`COUNT`, `SUM`, `AVG`, `GROUP BY`, `HAVING`) - *ဥပမာ: ဌာနအလိုက် ပျမ်းမျှလစာနှင့် OT စရိတ် စိစစ်ခြင်း*
- [ ] **Day 3:** Multi-table Relational Queries (`INNER JOIN`, `LEFT JOIN`) - *Employees, Salary History, Attendance tables များကို ချိတ်ဆက်ခြင်း*
- [ ] **Day 4:** Data Cleaning in SQL (`CASE WHEN`, `COALESCE`, `CAST`) - *လစာစာရင်း အမှားအယွင်းများ၊ Data မပြည့်စုံမှုများ ရှင်းထုတ်ခြင်း*
- [ ] **Day 5:** Advanced Window Functions (`ROW_NUMBER()`, `RANK()`, `PARTITION BY`) - *ဝန်ထမ်းများ၏ Salary Rank နှင့် Promotion History စိစစ်ခြင်း*
- [ ] **Day 6 & 7:** SQL Project 1 Complete - *“Enterprise Payroll Audit & Ghost Employee Detection Query Suite”*

- [ ] **Day 11:** Interactive Visuals, Drill-down & Slicers ဖန်တီးခြင်း
